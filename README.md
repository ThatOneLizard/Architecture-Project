# Architecture-Project
Repository for my 2026 Architecture class project

This project will involve using an Oz64 dev board along with a camera to train an AI model to recognize specific objects. I'll also be adding a button that's hooked up to the GPIO to trigger the detection. For this project, I'll be using dice from my D&D dice collection, since they come in a variety of shapes and colors that would help train the model to do better at detecting them.
